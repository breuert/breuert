## Python packages

- **[scrydb](https://github.com/breuert/scrydb)**: Lexical, dense and hybrid search with SQLite. Documents, embeddings and the lexical index are stored in a single SQLite file, and the library works with Sentence Transformers or precomputed embeddings. [[scrydb-eval]](https://github.com/breuert/scrydb-eval/), [[Hugging Face]](https://huggingface.co/datasets/breuert/scrydb-eval), [[arXiv]](https://arxiv.org/abs/2608.24060).

## Browser tools

- **[trec-eval-web](https://github.com/breuert/trec-eval-web)**: [trec_eval](https://github.com/usnistgov/trec_eval) in the browser. Load qrels and up to eight TREC runs to get trec_eval's measures as tables, cutoff plots, per-topic views and trec_eval's own text output, all in one offline HTML file. [[Live page]](https://breuert.github.io/trec-eval-web/).

- **[repro-eval-web](https://github.com/breuert/repro-eval-web)**: A browser dashboard for [repro_eval](https://github.com/irgroup/repro_eval). Load TREC runs and qrels to get reproducibility and replicability measures (KTU, RBO, RMSE, ER, ΔRI, t-tests) as tables, plots and exports, without data leaving your machine. [[Live page]](https://breuert.github.io/repro-eval-web/).

- **[rbo](https://github.com/breuert/rbo)**: An interactive explainer for rank-biased overlap (RBO) that shows how the persistence parameter *p* decides which ranks a score depends on. [[Live page]](https://breuert.github.io/rbo/).
